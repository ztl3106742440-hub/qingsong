## 发布前通过的检查

- 10 项 Node 原生测试：重复次序、完整分页、长单词断行、Unicode 字符、导入校验、旧版本迁移、空正文和极端页数。

- 768 × 1024 平板竖屏、1180 × 820 平板横屏、360 × 800 窄屏检查：无整页横向溢出；可见按钮、下拉与滑块触控高度至少 44 CSS px。

- 以“设置”视图为当前视图时打印，仍完整输出字帖，设置界面不会进入 PDF。
- 构建一致性、站内相对路径、原始字体 SHA-256、字体授权文件和发布资源清单检查。

## 明确的验证边界

- 自动化浏览器为 Windows 上的桌面 Chromium，平板与手机使用视口和触控模拟；没有把这些结果写成真实设备测试。
- Android / iPad 系统打印菜单、目标笔记软件导入与实际描红，需要用户在对应设备上确认。
- 已验证联网字体失败时的提示和降级；没有宣称每个联网字体均能在用户网络中加载。
- 当前版本没有 PWA 缓存、安装及断网冷启动承诺。
- GitHub Pages 公网部署结果另记于 `docs/DEPLOYMENT.md`。
