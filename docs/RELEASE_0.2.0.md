# 清松 0.2.0：平板触摸滚动与内置 PDF

日期：2026-10-27。用户反馈设备：华为平板，Chrome。

## 本次修复

竖屏的设置区继承了桌面滚动规则，预览区又同时使用 `overflow: hidden` 与 `overscroll-behavior: contain`。这些没有可滚动范围的容器会阻止触摸滚动继续传给外层文档，造成手指在内容上滑动却不移动页面。

竖屏现使用文档统一滚动，取消这些区域的滚动链阻断；1024 px 等较大平板竖屏也使用设置与预览切换。纸张的屏幕缩放单独裁切，避免为了修复滚动而引入横向溢出。切换工作区时保存各自的位置。

参考：https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior

## 内置 PDF

- 顶部按钮改为“下载 PDF”，在浏览器内直接创建文件，不调用系统打印。
- 仅输出字帖纸张，包括标题、作者、页码、辅助线、重复范字与深浅设置；设置面板和按钮不会进入文件。
- 预览与 PDF 共用分页结果和毫米纸张尺寸，支持五种纸张、横排、竖排、中文和英文。
- 实际字形使用所选字体的矢量轮廓，另保留 Unicode 检索与复制文字层。没有逐页截图或上传个人正文。
- PDF 库作为固定版本站内资源提供，仅第一次导出时加载；保存文件不依赖在线 PDF 服务。
- 导出期间锁定设置并显示进度，完成后解锁。若自动下载被浏览器阻止，可再点击页面显示的下载链接。
- 本地导入字体保留当前会话的字节供导出；联网字体还需能读取实际字体文件。字体缺字或读取失败会明确报错，不以其他字体静默替换。
- 设置区底部保留“备用：浏览器打印”。

## 字体兼容与体积

部分原始中文 WOFF2 使用变换后的字形表；直接使用字体子集可能出现“能提取文字但实际渲染空白”，并导致文件膨胀。当前导出将可见字形转为矢量路径，配合轻量 Unicode 文字层，绕过该兼容问题。

本次 11 个代表样张约 18～225 KB，检查不允许这些小样张异常膨胀到 2 MB 以上。

## 验证范围

- 原有 10 项数据与分页测试通过。
- 本地 21 组浏览器检查，包含原生触摸手势，而不仅是截图和元素尺寸检查。
- 触摸覆盖 768 × 1024、1024 × 1366 竖屏，1180 × 820 横屏与 360 × 800 窄屏；设置和预览均能滑动，页面无横向溢出。
- 60 种字号、字距、纸张与横竖排极值组合通过；装饰英文字体换行同时考虑字形外伸。
- 点击真实下载按钮得到 11 份 PDF，共 20 页，覆盖全部五套基础字体、自选字体和五种纸张。
- 核对实际页数、毫米尺寸、逐页正文及重复次数、末句、可见字形、文件体积，并确认没有整页截图对象。首末页渲染作视觉检查。
- PDF 缺字时恢复按钮和设置操作，不留下空白文件或过期下载链接。
- `public/vendor/VERSIONS.json` 记录固定 npm 版本、SHA-512 包完整性和站内文件 SHA-256，构建时核对代码和授权文件。

上述触摸检查仍为桌面 Chromium 通过 CDP 注入原生触摸事件，未宣称已在用户的实体华为平板操作。

见 `docs/FONT_GPT_HANDOFF.md`。该文件提供可直接复制的提示词、清单字段、打包要求、来源与授权证据要求，并区分字体资源与诗文内容的交接格式。
